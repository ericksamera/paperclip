How to capture papers

Paperclip captures pages via the Chrome or Firefox extension and saves everything locally.

Install the Chrome extension

  1. Open chrome://extensions
  2. Enable Developer mode
  3. Click Load unpacked
  4. Select the folder extensions/chrome from this repo

Install the Firefox extension

  1. Open about:debugging#/runtime/this-firefox
  2. Click Load Temporary Add-on…
  3. Select extensions/firefox/manifest.json

Firefox removes temporary add-ons when restarted.

Capture a paper

  1. Open an article page
  2. Click the Paperclip extension button
  3. Refresh the Library page to see it
